操作说明
鼠标
  • 左键单击节点：选中节点
  • Ctrl+左键单击节点：连续选择/取消选择多个节点
  • 左键在空白处拖拽：矩形框选多个节点（框选过程中靠近窗口边缘会自动滚动画布）
  • 拖拽选中的节点：将选中的一个或多个节点移动到目标节点下（支持拖入子节点或插入到同级位置）
  • 右键拖拽：平移视口（拖拽中可移出画布继续）
  • 滚轮：上下滚动画布
  • Alt+滚轮：左右滚动画布
  • Ctrl+滚轮：缩放视口
  • 小地图：点击跳转到对应区域；在视口框内按住拖动可平移
键盘
  • Home：回到根节点
  • 方向键：在父/子/同级节点之间导航
  • Enter：在当前节点后新增同级节点
  • Tab：为当前节点新增子节点
  • Delete / Backspace：删除选中节点（删除后优先选中同级上一个；若没有同级则选中父节点）
  • 双击 / F2 / 空格：编辑当前选中节点
  • Ctrl+A：全选
  • Ctrl+C：复制选中节点（复制为文本树，多行节点用`包裹）
  • Ctrl+V：将文本粘贴为当前节点的子节点（支持`包裹的多行节点）
  • Ctrl+Z：撤销（节点增删/改名/粘贴）
  • Ctrl+Y：重做
  • Ctrl+0：重置到 100% 实际大小
  • Esc：取消编辑
API 接口说明
使用方式
  • 在浏览器控制台中使用 window.MindMap 或直接 MindMap 访问接口
节点选择
  • MindMap.getSelectedNode() - 获取当前选中的节点对象
  • MindMap.getSelectedNodeId() - 获取当前选中节点的 ID
  • MindMap.selectNodeById(nodeId) - 根据 ID 选中节点
  • MindMap.selectNodeByName(name, exact=false) - 根据名称选中节点
节点修改
  • MindMap.setNodeName(nodeId, newName) - 修改指定节点的名称
  • MindMap.setSelectedNodeName(newName) - 修改当前选中节点的名称
节点添加
  • MindMap.addChild(parentId, name) - 向指定父节点添加子节点
  • MindMap.addChildToSelected(name) - 向当前选中节点添加子节点
  • MindMap.addChildren(parentId, names) - 批量添加多个子节点
节点删除
  • MindMap.deleteNode(nodeId) - 删除指定节点（及其子树）
  • MindMap.deleteSelectedNode() - 删除当前选中的节点
节点查找
  • MindMap.findNodesByName(name, exact=false) - 根据名称查找节点
  • MindMap.findNodeById(nodeId) - 根据 ID 查找节点
  • MindMap.getAllNodes() - 获取所有节点列表
  • MindMap.getNodeCount() - 获取节点总数
折叠/展开
  • MindMap.collapseNode(nodeId) - 折叠指定节点
  • MindMap.expandNode(nodeId) - 展开指定节点
  • MindMap.expandAll() - 展开所有节点
  • MindMap.collapseAll() - 折叠所有节点
视图控制
  • MindMap.zoomTo(scale) - 缩放到指定比例 (0.1-4.0)
  • MindMap.zoomIn() - 放大 10%
  • MindMap.zoomOut() - 缩小 10%
  • MindMap.resetView() - 重置视图到原始状态
使用示例
  • MindMap.setSelectedNodeName('新名称')
  • MindMap.addChildToSelected('子节点')
  • MindMap.addChildren(0, ['A', 'B', 'C'])
  • MindMap.selectNodeById(5)
  • MindMap.deleteSelectedNode()
