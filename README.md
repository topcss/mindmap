# MindMap MT

> 思维导图是被严重低估的基础设施。在智能体时代，它理应被重新发明。

**[👉 在线使用](https://topcss.github.io/mindmap.html?dataset=blank)** — 无需安装，打开浏览器即可开始

![MindMap MT 网页版界面](./docs/mindmap-web-screenshot.png)

## 我们的出发点

思维导图是个人与团队组织思想的基本工具。然而放眼市场，现有产品都差了一口气：

- **商业产品**：体验出色，但收费，免费版存在节点限制——你的思路被锁在付费墙里。
- **开源产品**：开放自由，但体验与商业产品差距悬殊——你愿意用，却难以真正用起来。
- **智能体时代**：写计划、写方案、做梳理，AI 随手就能生成结构化的思维导图。但市场缺少一个**不设限、体验好、且 AI 天生会用**的工具来承接这一切。

因此，我们决定从 0 开始，做一个同时具备**开源的开放性**与**商业产品的易用性**的思维导图——在智能体时代，像 Markdown 之于写作一样，成为思想组织的基础设施。

## 产品理念

### 克制：砍掉一切不必要的

商业产品之所以依赖二进制格式，是因为要支撑大量扩展功能：备注、多主题样式、任意连线……这些功能带来了灵活性，却也带来了格式臃肿、文件不可读、AI 无法参与。

我们的选择是**全部砍掉**：

| 砍掉 | 保留 |
| --- | --- |
| 备注 | 节点 |
| 多主题样式 | 层级 |
| 自由连线 | 文字 |
| 私有格式 / 加密 / 云绑定 | 纯文本 |

**只保留最核心、最常用的能力。** 定位是三个词：**简单、高效、易用**。这份克制正是全部价值的来源——因为少，格式才能保持纯文本；因为纯文本，人与 AI 才能在同一份文件上协作。

### 纯文本：人与 AI 的共同语言

`.mt` 是纯文本格式，因此拥有其他思维导图不具备的自由度——**同一张图，人和 AI 都能直接参与**：

- **可视化编辑**：在网页或 VS Code 插件中，像使用商业产品一样拖拽、双击、随心布局。
- **手动修改**：打开就是普通文本，在任何编辑器里逐字修改，比操作图形界面更快、更精准。
- **大模型参与**：AI 天然擅长读写文本，将 `.mt` 交给它，生成、扩写、重构、总结，一气呵成。

无需转换、无需导出、无需格式桥接。**人和 AI 在同一份文件上协作，这才是思维导图正确的打开方式。**

## 产品组成

三者共用同一种 `.mt` 格式，一个文件、处处可用：

| 场景 | 形态 | 说明 |
| --- | --- | --- |
| 随时随地 | [在线单文件版](https://topcss.github.io/mindmap.html?dataset=blank) | 打开即用，无需安装，可离线下载 [`mindmap.html`](./mindmap.html) 随手分享 |
| 写代码的地方 | [VS Code 插件](./extensions/mindmap-mt/) | 在编辑器内直接打开、编辑、自动保存 `.mt` 文件 |
| 大模型协作 | [LLM 技能](./skills/mindmap-format/) | 教会 AI 书写 `.mt` 格式，让 AI 成为你的导图共创者 |

## 智能体时代的工作流

在智能体时代，思维导图从「记录工具」进化为「思考界面」：

- **写计划**：让 AI 生成计划大纲 → 展开为可视化导图 → 边想边改，实时落盘。
- **写方案**：用导图组织论点与结构 → 让 AI 基于导图生成完整文稿。
- **做梳理**：把零散想法交给 AI → 整理为结构化导图 → 反复迭代。

你的想法不再停留在文档里，而是在一张活的、可随时生长的图上展开。而这一切，**免费、开放、无节点限制**。

## 快速开始

1. **在线使用**：[点击在线使用](https://topcss.github.io/mindmap.html?dataset=blank)，无需安装；或下载 [`mindmap.html`](./mindmap.html)，双击打开即可离线使用。
2. **在 VS Code 中使用**：安装 `extensions/mindmap-mt` 打包的插件（或按 `F5` 进入开发调试），双击 `.mt` 文件即获得图形化编辑体验，支持自动保存。
3. **让 AI 为你生成导图**：将 [`skills/mindmap-format`](./skills/mindmap-format/) 加载到你的 Agent 中，向 AI 说"请帮我生成一份计划思维导图"，它即可输出规范的 `.mt` 文件，在任何场景直接打开。

## .mt 格式规范

```
根节点
    节点1
    节点2
        子节点2.1
        子节点2.2
```

- 纯文本格式，每个节点占一行
- 缩进表示层级，每级缩进 4 个空格
- 多行内容用反引号包裹
- 完整规范见 [`skills/mindmap-format/SKILL.md`](./skills/mindmap-format/SKILL.md)

它足够简单，AI 一学就会；足够通用，能成为你长期的思维资产。
