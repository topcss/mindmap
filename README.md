# MindMap MT — 智能体时代的新思维导图基础设施

> 思维导图是被严重低估的基础设施。在智能体时代，它理应被重新发明。

## 为什么还要做一个思维导图？

因为现有的选择都差了一口气：

- **商业产品**：体验好，但收费，免费版有节点限制——你辛苦整理的思路，被卡在付费墙里。
- **开源产品**：免费、开放，但体验和商业产品差距太大——你愿意用，却用不下去。
- **而大模型时代**：写计划、写方案、做梳理，AI 随手就能输出结构化的思维导图。但你缺少一个**不设限、体验好、且 AI 天生会用**的工具来接住它。

我们相信，思维导图在智能体时代会成为个人和团队**思维组织的基础设施**——就像 Markdown 之于写作。它的形态应该是：

> 拥有开源的开放性，也拥有商业产品的易用性。

**MindMap MT** 就是这样一个项目：从 0 开始，做一个在大模型加持下无比流畅的思维导图。

## 它是什么

一个围绕 `.mt` 纯文本格式构建的全场景思维导图方案，覆盖你用得上的每一个场景：

| 场景 | 形态 | 说明 |
| --- | --- | --- |
| 随时随地 | [在线单文件版](./mindmap.html) | 一个 HTML 文件，双击即用，零依赖、可离线、可随手分享 |
| 写代码的地方 | [VS Code 插件](./extensions/mindmap-mt/) | 在编辑器里直接打开、编辑、自动保存 `.mt` 文件 |
| 大模型协作 | [LLM 技能](./skills/mindmap-format/) | 教会 AI 书写 `.mt` 格式，让 AI 成为你的思维导图共创者 |

三者共用同一种 `.mt` 格式，一个文件，处处可用，AI 与你无缝衔接。

### 最独特的亮点：纯文本，三种打开方式

`.mt` 是纯文本格式，因此它有着其他思维导图都不具备的自由度——**同一张图，人和 AI 都能直接参与**：

- **可视化编辑**：在网页或 VS Code 插件里，像使用商业产品一样用鼠标拖拽、双击、随心布局。
- **手动修改**：打开就是普通文本，任意编辑器里逐字修改，比操作图形界面更快、更精准。
- **大模型直接参与**：AI 天然擅长读写文本，把 `.mt` 交给它，生成、扩写、重构、总结，一气呵成。

无需转换、无需导出、无需格式桥接。**人和 AI 在同一份文件上协作，这才是思维导图正确的打开方式。**

### 我们的取舍：砍掉一切不必要的

为什么商业产品都使用二进制文件？因为要支撑更多功能——备注、任意连线、多主题样式……而正是这些花哨的功能，让格式变得臃肿，让文件不再可读，也让 AI 无法参与。

我们选择**全部砍掉**：

- ✂️ 不要备注、不要多主题、不要自由连线
- ✂️ 不要加密、不要私有格式、不要云绑定
- ✅ 只保留最核心、最常用的：节点、层级、文字

我们把它刻意做小。**定位就是：简单、高效、易用。**

这份克制，正是全部价值的来源——因为砍掉了多余的功能，`.mt` 才能保持纯文本；因为保持纯文本，人和 AI 才能在同一份文件上协作。**少即是多。**

## 大模型加持下的工作流

在智能体时代，思维导图从「记录工具」变成了「思考界面」：

- **写计划**：让 AI 生成计划大纲 → 图形化展开成思维导图 → 边想边改，实时落盘。
- **写方案**：用导图组织论点与结构 → 让 AI 基于导图生成完整文稿。
- **做梳理**：把零散想法丢给 AI → 一键整理成结构化导图 → 反复迭代。

你的想法不再停留在文档里，而是在一张活的、可随时扩展的图上生长。而这一切，**免费、开放、无节点限制**。

## 如何开始

### 立刻体验

下载 [`mindmap.html`](./mindmap.html)，双击打开即可使用。

### 在 VS Code 中使用

在 VS Code 中安装 `extensions/mindmap-mt` 打包出的插件（或按 `F5` 进入开发模式），双击 `.mt` 文件即可获得图形化编辑体验，支持自动保存。

### 让 AI 为你生成思维导图

将 [`skills/mindmap-format`](./skills/mindmap-format/) 加载到你的 Agent 中，对 AI 说"请帮我生成一份计划思维导图"，它就能输出规范的 `.mt` 文件，直接在任何场景中打开。

## .mt 格式：简单到 AI 与人都能掌握

```
根节点
    节点1
    节点2
        子节点2.1
        子节点2.2
```

- 纯文本、每个节点占一行、缩进表示层级（每级 4 空格）
- 多行内容用反引号包裹
- 完整规范见 [`skills/mindmap-format/SKILL.md`](./skills/mindmap-format/SKILL.md)

它够简单，所以 AI 一学就会；够通用，所以能成为你的长期思维资产。

## 愿景

我们想为智能体时代搭建一块基础设施：**让每个人的思考，都能自由地展开成图，并且永远不被锁住。**

MindMap MT 是开源、开放的。欢迎参与，一起把思维导图重新做一遍。
