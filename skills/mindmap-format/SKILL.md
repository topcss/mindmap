# 思维导图格式 (.mt)

思维导图使用 `.mt` 后缀的纯文本文件，格式规则如下：

## 基本规则

1. 文件扩展名为 `.mt`
2. **每个节点占一行**
3. **缩进表示层级**：每级缩进4个空格
4. **节点内容**：直接写文本，多行内容用反引号 `` ` `` 包裹

## 多行节点

当节点内容包含多行文本或特殊字符时：
- 用反引号 `` ` `` 包裹整个内容
- **必须**转义内容中的反引号：使用 `\`` 转义每个 `` ` `` 字符

## 示例

```mt
根节点
    节点1
    节点2
        子节点2.1
        子节点2.2
    节点3
```

```mt
会议纪要
    议题
        `议题1：预算评审
会议讨论了Q3预算分配方案
各部门需在周五前提交修订版`
    决议
        批准市场部预算
        技术部预算需重新评估
    待办事项
        张伟 - 修订预算报告
        李娜 - 收集Q2数据
```

```mt
`包含\`特殊字符\`的节点
注意反斜杠转义`
```

## 缩进规范

- 根节点：顶格（无缩进）
- 子节点：1级 = 4空格，2级 = 8空格，依此类推
- 同级节点保持相同缩进
